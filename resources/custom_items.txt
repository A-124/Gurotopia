# Gurotopia custom content configuration
#
# ITEM FORMAT (one item per line):
# item|id|name|base_item|type|rarity|tradeable|texture_path|info|render_base_item(optional)
#
# Fields:
# id          = unique custom item ID (1000-65535; do not reuse vanilla IDs)
# name        = item name shown in inventory and dialogs
# base_item   = vanilla item ID used for server-side behavior/runtime metadata
# render_base_item = optional vanilla item ID used as the client record/render template;
#                    useful when a different item has more suitable sprite/render metadata
# type        = item type/action_type (e.g. 20 = clothing; usually match base_item)
# rarity      = rarity number shown in item info
# tradeable   = 1 allows dropping/trading; 0 marks it untradeable
# texture_path= client texture path in items.dat (e.g. game/Leey_Katana.rttex)
# info        = text shown in the /info item dialog; do not use the | character
#
# NOTE: the server passes the configured .rttex asset through; it does not resize or pad it.
# To test a larger canvas, replace resources/custom_assets/Leey_Katanav5.rttex with your
# larger .rttex file and keep the texture path below. Client rendering may still impose limits.
#
# The server loads texture files from resources/custom_assets/ using the basename
# of texture_path. Keep the texture_path in the same format as vanilla items.dat.
#
# CUSTOM BLOCK FORMAT:
# lucky_box|id|name|base_item|texture_path|drop_id,drop_id,...
#   Drop IDs are weighted by position: with 4 IDs, their weights are 4, 3, 2, 1.
#   Therefore the leftmost item is most likely and the rightmost is least likely.
# pot_gold|id|name|base_item|texture_path|min_gems,max_gems
#   Pot Gold drops a random number of gems between min_gems and max_gems (inclusive).
# base_item should be a vanilla block whose rendering/behavior metadata is suitable.
# Textures are loaded from resources/custom_assets/ by basename; use game/<filename> in the config.
#
# RECIPE FORMAT (one recipe per line):
# recipe|result_id|result_amount|ingredient_id:amount,ingredient_id:amount
#
# Example recipe: make 1 item 20000 using two of item 2:
# recipe|20000|1|2:2
#
# Leey Katana: clones Legendary Katana (ID 2592).
item|20000|Leey Katana|2592|20|10|1|game/Leey_Katanav5.rttex|A custom katana made for Gurotopia.|2592
recipe|20000|1|2:2

# Custom blocks (IDs must not overlap vanilla item IDs).
# Lucky Box weights: 2=50%, 10=33.3%, 18=16.7% with this three-entry list (no gem reward).
lucky_box|30000|Lucky Box|2|game/Lucky_box.rttex|2,10,18
# Pot Gold drops a random 1 to 50 gems per break; adjust either bound as desired.
pot_gold|30001|Pot Gold|2|game/Pot_Gold.rttex|1,50
