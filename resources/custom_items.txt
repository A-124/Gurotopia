# Gurotopia custom content
#
# This file defines custom items, custom blocks, and crafting recipes.
# Apply changes without restarting the server with: /reload content
# Lines starting with # are comments and are ignored.


# =====================================================================
# 1. CUSTOM ITEMS
# =====================================================================
#
# One item per line, with these fields in this order:
#
#   item|id|name|base_item|type|rarity|tradeable|texture_path|info|render_base_item|icon_texture|icon_slot
#
#   id           Unique custom ID, from 1000 to 65535. Never reuse a vanilla item ID.
#   name         Name shown in the inventory and dialogs.
#   base_item    Vanilla item ID used for server-side behavior and metadata.
#   type         Item/action type. Usually the same as base_item (20 = clothing).
#   rarity       Rarity number shown in the item info.
#   tradeable    1 = can be dropped and traded, 0 = cannot be traded.
#   texture_path Client texture path, as in items.dat (e.g. game/Leey_Katana.rttex).
#                The server loads the file by its name from resources/custom_assets/.
#   info         Text shown by /info. Do not use the | character here.
#   render_base_item (optional)
#                Vanilla item ID used as the client render template. Useful when
#                another item has better sprite metadata. Leave empty if not needed.
#   icon_texture (optional)
#                A second texture for the small inventory icon (e.g. a 32x32 file),
#                so the main texture can be 64x64 while the icon stays small.
#                To use an icon without a render base, write it as || (empty render base).
#   icon_slot    "extra" (default) or "main".
#                  extra: texture_path goes in the main slot and icon_texture in the
#                         extra file slot.
#                  main:  the two are swapped.
#                If the icon does not change in game with "extra", use "main".
#
# TEXTURE SIZE
# The server does not resize or pad textures. RTTEX canvases must be a power of two,
# so a 48x16 sprite must sit on a 64x64 (or 64x16) canvas. Build one with:
#
#   python tools/png_to_rttex.py art.png resources/custom_assets/Name.rttex
#
# The default canvas is 64x64 with the art in the top-left corner. When the server
# starts, it prints each custom texture's canvas size, for example:
#   texture Leey_Katana64.rttex canvas 64x64

# Leey Katana: a copy of the Legendary Katana (ID 2592).
item|20000|`cLeey Katana|2592|20|10|1|game/Leey_Katanav2.rttex|A custom katana made for Gurotopia.|2592|game/Leey_Katanav2.rttex|extra

# =====================================================================
# 3. CUSTOM BLOCKS
# =====================================================================
#
# Block IDs must not overlap vanilla item IDs.
# Textures are loaded the same way as items: use game/<filename> and place the file
# in resources/custom_assets/.

# Lucky Box
#   lucky_box|id|name|base_item|texture_path|drop_id,drop_id,...
#
#   Drops are weighted by position. With N drop IDs, the first gets weight N, the
#   second N-1, and so on, down to 1 for the last. The first item is the most likely.
#
#   This box has 8 drops, so the total weight is 36:
#     2      22.2%     160     19.4%     2228    16.7%     2874    13.9%
#     7276   11.1%     4626     8.3%     9698     5.6%     11340    2.8%
#   There is no gem reward.
#
#   ID 30001 is reserved for the future Lucky Box Seed.

lucky_box|30000|`cLucky Box|2|game/Lucky_box.rttex|2,160,2228,2874,7276,4626,9698,11340


# Pot Gold
#   pot_gold|id|name|base_item|texture_path|min_gems,max_gems
#
#   Drops a random number of gems from min_gems to max_gems (inclusive).
#   base_item should be a vanilla block with suitable rendering and behavior.
#   Pot Gold uses ID 30002.

pot_gold|30002|`cPot Gold|2|game/Pot_Gold.rttex|1,100
